### 项目功能说明

1️⃣ 添加地点：点「记一笔」，输入地名后点「定位」自动找到坐标，上传照片、写下日期和心情，保存后地球对应位置就会亮起光点

2️⃣ 浏览回忆：拖拽或滑动旋转地球，点击任意光点查看那次旅行的照片和记录，还能"飞到这里"让地球转到对应位置

3️⃣ 数据安全：所有数据存在本地浏览器，支持一键导出/导入备份，方便跨设备迁移

4️⃣ 技术栈：Three.js（r128）+ 原生 JavaScript / CSS，零构建步骤，单 HTML 文件部署于 GitHub Pages

5️⃣ 技术亮点：地球贴图用 Canvas 程序化绘制（不依赖任何外部图片）、自定义着色器实现大气辉光、照片上传自动压缩以适配本地存储、定位采用"内置常见城市表＋联网兜底"双层方案


### vibe coding 过程

1️⃣ 想法到第一版
定下技术路线——纯前端、Three.js 渲染地球、数据存本地、单文件部署。骨架很快跑通：可旋转的地球、添加地点、点击看照片。

2️⃣ 推翻重做风格
第一版是水彩手账风，看过效果后我决定整体换成深空科技风，几乎推倒重来。这让我体会到 vibe coding 的价值：看到效果后能低成本地大改方向。

3️⃣ 对着真实使用打磨
大陆贴上洲名、界面全中文、给按钮加说明、截图反馈遮挡问题、上下滑动总在缩放而不是旋转……需求是在用的过程中长出来的，而非一开始想清楚的。
